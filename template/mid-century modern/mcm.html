a visual guide to mid-century modern style

When I first opened this project I nearly cried. I wasn't expecting the css page to be completely blank. I tried messing around with it and eventually made a structure that worked. I took it one step at a time and focused on the html page as some of the images where misplaced and there needed to be some gaps in the article. I then connected the css file by inserting the link rel="stylesheet... I then added the Google Fonts and built my css frame. I rewatched one of the Zoom meeting recordings to get some idea of how to move forward with the css file and looked online for YouTube tutorials where I had issues. One of the main issues I had was these orange gaps inside of the article. When I was designing it in css I essentially made three seperate blue rectangles and in the assignment picture the blue background is supposed to look like one continuous column. I added another line at body > . wrap and added a margin-top with a negative amount of pixels because I wanted to see if that can help with the gaps. I was messing around with -5px to -10px then finally -17px did the job and pulled the element closer to my other element.
