Process Reflection

During this project, I learned more about the CSS box model and how different properties like margin, padding, borders, and backgrounds affect the way elements look on a webpage. I also practiced using the display property to change how elements are arranged. One of the challenges I had was adding my logo and dropdown menu to this Box Model page. I struggled with the CSS because the links kept getting the yellow backgrounds and black borders from the styles I created for the assignment. I had to figure out how to change the styles for only specific links without affecting the rest of the page...it was kind of like playing Jenga in CSS. Overall the project helped me understand CSS selectors can affect multiple elements along with how it works together with HTML.
